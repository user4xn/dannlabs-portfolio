# Portfolio Redesign Commit Sheet

## Direction
Warm interactive portfolio: human-first personal branding with technical grid texture, modular project showcase, smooth motion, and Snowy as a public AI assistant case study.

## Peak
Snowy panel: a white cat assistant responds while a safe activity trace shows bounded public-agent behavior.

## Color
Warm off-white base, charcoal ink, rust/orange signal accent, dark technical band. No purple-blue gradient, no neon overload.

## Type
Characterful display serif + readable sans + mono metadata. The page must remain recruiter-readable before interaction.

## Grid break
Technical grid is a quiet layer behind content; project media and Snowy panel interrupt it instead of sitting in identical cards.

## Motion budget
Three families: soft section reveals, project hover/expand, cursor swarm. All have reduced-motion fallbacks.

## Reflex check
Generic portfolio reflex: dark developer dashboard with terminal copy and technology badges. Avoid it with warm light surfaces, clear prose, project visuals, and animation used as navigation rather than decoration.

## House tells broken
1. No hero-metric wall; proof lives in project context.
2. No generic chatbot hero; Snowy appears after the engineer identity and project proof are established.
