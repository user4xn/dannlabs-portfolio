# dannlabs portfolio

A static HTML/CSS/vanilla JavaScript portfolio for `dannlabs.my.id`.

No React, Next.js, Tailwind, npm, bundler, or runtime is required. Open `index.html` directly or serve this folder with any static HTTP server.

## Structure

- `index.html` — semantic page shell
- `src/js/data/` — editable portfolio data
- `src/js/components/` — DOM components
- `src/js/animations/` — motion behavior
- `src/styles/` — modular CSS: tokens, base, components, motion, responsive
- `assets/` — approved portfolio media

The public Snowy interaction is currently a local demo placeholder. The isolated public Snowy agent/API is a later phase and is not connected to the private Hermes runtime.
