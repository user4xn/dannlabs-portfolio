# Public projects

## ShipDude
Self-hosted deployment tooling for small teams. Built with Go, Docker, and GitHub Actions. It bootstraps a VPS with reverse proxy, CI/CD pipeline, and container runtime; supports health checks, rollback, and execution logs.

## Danz Pos
Offline-first cashier PWA for buffet restaurants. Uses React, Vite, PWA patterns, and cloud sync. Includes cashier flow, order queue, tax handling, thermal receipt printing, and sales reports.

## SIMPLE — Ship Parking
Private vessel tracking and geofencing product. Uses Go, WebSocket, and Node.js. It derives harbour check-in/check-out from live GPS positions and uses map polygons for boundaries.

## Lemparkoin
Donation and live-overlay platform for streamers. Built and tested, not released. Uses Go, RabbitMQ, Redis, and PostgreSQL. Public-safe features include wallet top-up/withdrawal, platform fee, transaction history, OBS browser-source overlays, donation alerts, text-to-speech, and settlement events.
